# Etch-a-Sketch

## Description
In this project, I am building a browser-based sketchpad and Etch-a-Sketch toy as part of The Odin Project curriculum. Users will be able to draw on a customizable grid by hovering their mouse over the squares and change the grid size dynamically.

## Skills to Practice
Through this project, I plan to practice and reinforce the following skills:
- **HTML:** Structuring the basic layout and container elements for the sketchpad.
- **CSS:** Using Flexbox to arrange the squares into a neat grid and styling the interface.
- **JavaScript:** Writing functions to generate grid elements dynamically and handle user inputs.
- **DOM Manipulation:** Creating, modifying, and removing HTML elements via JavaScript, as well as adding event listeners for mouse hover effects.
